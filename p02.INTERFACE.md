# p02 interface — FROZEN before the writer runs

This file is the contract between the generator (`pipeline_pisa/build_data.py`, which fills `/*__DATA__*/`) and the
six renderers inside `p02.template.html`. Both sides follow it literally. Change it only by patching this file and
the generator in the same change. Every key named here MUST exist in the payload; a renderer may read no key that
is not named here, and the generator may emit no key a renderer needs that is not named here.

## 1. Payload shape

    DATA.meta   = { cycle: 2025, retrieved: "2026-10-13",
                    source_url: "https://www.oecd.org/en/data/datasets/pisa-2025-database.html",
                    annex_sha256: "<hex>", puf_sha256: "<hex>", licence: "CC BY 4.0" }
    DATA.hero   = { idn:  { scie: 388.67379, se: 2.31865 },
                    oecd: { scie: 481.90834, se: 0.43835 },
                    cut_l2: 409.54, cut_unit: "poin skor" }
    DATA.trend  = [ { cycle: 2006, idn: 393.48102, idn_se: 5.73, oecd23: 502.74367, oecd23_se: 0.60 }, ... ]
                   one entry per cycle, 2006 2009 2012 2015 2018 2022 2025, ascending

                               cut_scores: [260.54,334.94,409.54,484.14,559.74,633.33,708.16],

                    reading: { bands: ["level_below_1c","level_1c","level_1b","level_1a","level_2","level_3","level_4","level_5","level_6"],

    DATA.fig    = flat map of string/number values for every span[data-fig] in the template, keyed by the
                  attribute value, each either a scalar or {d: <display string>}. The generator SCANS the

                  when a span has no value: a headline number is a claim and may not be typed by hand.
                  Headline numbers used by this page (all in the same Indonesian number format as the rest of

## 2. Element ids and renderers (one owner each, never shared)

    #hero-scale     renderHero()         DATA.hero
    #trend-chart    renderTrend()        DATA.trend
    #prof-chart     renderProficiency()  DATA.prof
    #spread-chart   renderSpread()       DATA.spread
    #escs-chart     renderEscs()         DATA.escs
    #peers-chart    renderPeers()        DATA.peers

Rule that binds every renderer: clear its own container first (`container.replaceChildren()`), build one inline
`<svg>` with an explicit `viewBox`, set `font-size` on every `<text>` (never inherit the page's), and never create
a missing container: if `document.getElementById(...)` returns null, throw.

## 3. Chart specification per band

3.1 **hero** — ONE horizontal score axis spanning 250 to 650 score points, drawn as the band's cut-score ruler:
  a baseline with ticks every 50 points labelled in mono, a marked vertical line at the Level-2 cut score
  (409,54) with the label "AMBANG LEVEL 2", one marker for Indonesia (388,67) and one for the OECD average
  (481,91), each with its value printed at the marker and a 2*S.E. whisker. Indonesia in `--series-idn`,
  the OECD in `--series-oecd` plus the hatch pattern. This drawing IS motif slot 1: real values, unit, caption.

3.2 **trend** — a two-series line/step chart, x = cycle (2006 2009 2012 2015 2018 2022 2025, evenly spaced,
  labelled), y = score points from 360 to 520. Indonesia highlighted in `--series-idn`, OECD average-23 in
  `--series-oecd` with the hatch. Each point carries a whisker of +/- 1 S.E. Direct labels at the last point of
  each series, no legend box. Caption states that both comparators are the same window.

3.3 **proficiency** — a 100%-stacked horizontal bar per domain per population (science, reading, mathematics;
  Indonesia and OECD), bands in the ordered `--level-*` ramp, the below-Level-2 region called out with a bracket
  and its percentage as the band's number. Redundant encoding is mandatory: each band carries its own numeric
  label where it is wide enough, and a legend row names the bands; identity never rests on hue alone. Neighbour
  steps cannot reach 3:1 against each other (8 steps cannot), so the hatch plus labels carry the classes and the
  3:1 requirement applies only between each band and the ground.

3.4 **spread** — two horizontal box-and-whisker rows on ONE shared score axis: p10-p25-p50-p75-p90 for Indonesia
  and for the OECD average, values printed at each marker. The band's line: Indonesia's p90 (477,62) sits below
  the OECD's median (483,50).

3.5 **escs** — a small-multiple: four quartile bars per population on one axis, Indonesia beside the OECD, each
  bar labelled with its score. Below the bars, motif slot 2: the ESCS cut-score ruler, Indonesia's three cut
  points on the top row and the OECD's three on the bottom row, with the unit named and a caption saying the two
  scales are not comparable across systems.

3.6 **peers** — a ranked ladder: one horizontal bar per country, no axis, the value printed at the bar end, the
  country name at the left, Indonesia's bar in `--series-idn` and every other bar in a neutral fill. Ordered
  descending by value. A dashed reference line marks the OECD average (481,91) with its label.

3.7 **method** — static copy plus the `[data-fig]` slots, already in the template. Its motif slot 3 (the one
  standard error ruler) stays where it is; the drawn bar must keep the declared scale honest: the bar's width in
  px equals the science S.E. (2,31865) multiplied by the scale declared in the same panel (px per score point).

## 4. Copy rules

- Every visible word is Indonesian. No em dash. No number typed into markup outside a `[data-fig]` fallback.
- A band headline states its finding, not its chart type, and never claims a cause.
- The word "signifikan" may only be used where the change exceeds twice its own S.E.
- The page states plainly what it does not claim: no causality, no subnational breakdown (the Indonesian sample
  is national), and nothing about 15-year-olds who are not enrolled in school.
